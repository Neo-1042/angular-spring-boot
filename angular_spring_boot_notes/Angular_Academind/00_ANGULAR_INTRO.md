# What is Angular?

Angular is a frontend JavaScript framework that helps build
interactive, modern web user interfaces. It is also a collection
of tools:

- CLI (ng)
- Debugging tools
- IDE pluggins

You don't really need Angular for simple web applications.
Angular simplifies the process of building complex, interactive
web user interfaces, especially for enterprise web applications.

- Angular -> **Declarative Code**
- Vanilla JavaScript -> **Imperative Code**

With Vanilla JavaScript, you have to explicitly write every DOM
element, every CSS class. That is, you have to explicitly tell
the browser what to do with the DOM, events, and so on.

With Angular, you define the target UI and how it should behave.
Angular takes care of interfacing with the browser, letting
the developer focus on the app functionality itself.

Angular embrace most of the **OOP concepts** (dependency
injection, classes, inheritance, interfaces)

## Angular Components

Angular separates concerns via **components**, which are
identified by custom HTML elements.

***Angular uses TypeScript!***

> Angular in summary:

1. Declarative Code (abstraction from imperative code)
2. Components
3. Object-Oriented Programming
4. TypeScript
