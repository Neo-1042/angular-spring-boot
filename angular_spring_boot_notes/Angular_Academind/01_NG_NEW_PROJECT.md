# Angular CLI

> Angular uses TypeScript and a specific HTML syntax that does
not natively work with the browser. Therefore, you need to
install the Angular CLI in order to translate (transpile) the
Angular project code into code that can be run by the browser.

```bash
# Install a compatible version of NodeJS: (nvm must be installed)
# nvm install 24.11.0
# nvm 
npm install -g @angular/cli
```

## Create a New Angular Project

```bash
ng new my-angular-project --no-zoneless
```
